## AI Coding Agents
- [ccg-gateway](https://github.com/mos1128/ccg-gateway): 为 Claude Code、Codex、Gemini CLI 提供网关和配置管理，适合服务商不稳定、需要频繁切换的场景。
- [Quotio](https://www.quotio.dev/): AI coding assistant 的 command center。
- [你不知道的 Agent：原理、架构与工程实践](https://tw93.fun/2026-03-21/agent.html): 一篇偏工程化的 Agent 长文。
- [autoresearch](https://github.com/karpathy/autoresearch): 自动研究流程的探索，适合闭环实验类任务。
- [Harness Engineering — Agent 不好用，也许不是模型的问题](https://yuanchaofa.com/post/harness-engineering-for-ai-agents): 强调 harness 设计对 Agent 可用性的决定性作用。
- [Codex use cases](https://developers.openai.com/codex/use-cases): OpenAI官方codex使用场景集合。
- [Understand large codebases | Codex use cases](https://developers.openai.com/codex/use-cases/codebase-onboarding): 面向大仓库理解与改造流程的实践建议。
- [Codex Plugins](https://developers.openai.com/codex/plugins): Codex 插件系统。
- [Claude Code Cheat Sheet](https://cc.storyfox.cz/): 常用指令速查。
