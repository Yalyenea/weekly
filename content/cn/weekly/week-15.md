### AI / Agent / 编程工作流

[Manggo](https://manggo.pylogmon.com)：Pot 不再维护后，作者推出的新翻译工具。原 [Pot](https://pot-app.com/) 仍可作为迁移背景参考。

[opendatalab/Sciverse-Agent-Tools](https://github.com/opendatalab/Sciverse-Agent-Tools)：面向 Sciverse Open Platform 的 agent 工具 schema 与 SDK，把检索能力整理成 LLM agent 可调用的标准工具。

[Terax](https://terax.app/)：terminal-first 的 AI-native dev workspace，偏向把 AI 开发工作流放回终端环境。

[Gitlawb/zero](https://github.com/gitlawb/zero)：强调本地、自主、可控的 coding agent，口号是你的模型、机器和规则由你决定。

[Tiktokenizer](https://tiktokenizer.vercel.app/)：在线 tokenizer 观察工具，适合快速看文本如何被 token 化。

[偷懒工具](https://toolight.cn/)：一组在线小工具集合，偏日常效率场景。

[UniClipboard](https://github.com/uniclipboard/uniclipboard)：local-first、P2P、端到端加密的跨设备剪贴板同步工具，不依赖账号和云端中转。

### 机器学习 / 优化 / 课程

[Random Reshuffling Dominates Stochastic Gradient Descent](https://arxiv.org/abs/2606.32005)：证明在光滑凸优化中，合理步长下 random reshuffling 在任意有限 epoch 后都优于 SGD，回答了一个长期开放问题。

[Orca: The World is in Your Mind](https://huggingface.co/papers/2606.30534)：world model 方向论文页面，关注模型内部世界表征与预测能力。

[Reinforcement Learning of Large Language Models](https://ernestryu.com/courses/RL-LLM.html)：大语言模型强化学习课程材料。

[DSC 243: Convex Quadratics](https://ddrusvyat.github.io/DSC-243/)：高级优化课程中关于凸二次函数的讲义。

[Pen and Paper Exercises in Machine Learning](https://arxiv.org/abs/2206.13446) / [GitHub](https://github.com/michaelgutmann/ml-pen-and-paper-exercises)：机器学习纸笔练习集，适合作为概念推导和考试型训练材料。

[Presentations](https://michaelgutmann.github.io/presentations/)：Michael Gutmann 的统计机器学习相关 presentation 集合。

[Machine Learning Visualized](https://ml-visualized.com/)：机器学习概念可视化材料。

[IClimbTrees](https://www.iclimbtrees.com/courses)：AI 与机器学习课程集合。

### 信号 / 雷达 / 音频

[How I built a mmWave material classification radar](https://gauthier-lechevalier.com/radar)：毫米波材料分类雷达的个人项目记录，包含硬件、信号与实验实现。

[AudioMass](https://audiomass.co/)：在线音频编辑器，适合轻量剪辑和波形处理。

### 计算机基础 / 理论 / 工程文章

[CS-Fundamentals](https://github.com/Krishnagangwal/CS-Fundamentals)：面向求职准备的计算机基础资料，覆盖 DSA、计算机网络、DBMS / SQL、OOP、操作系统、系统设计与软件工程。

[Respect the P v NP Problem](https://blog.computationalcomplexity.org/2026/06/respect-p-v-np-problem.html)：Computational Complexity 博客关于 P vs NP 问题的评论文章。

[(Quite) A Few Words About Async](https://yoric.github.io/post/quite-a-few-words-about-async/)：关于异步编程的长文，适合回看 async 的设计动机和复杂性来源。
