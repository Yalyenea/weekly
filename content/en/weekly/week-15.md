### AI / Agent / Programming Workflow

[Manggo](https://manggo.pylogmon.com) — a new translation tool from the author of Pot after Pot entered maintenance mode. The original [Pot](https://pot-app.com/) is still useful migration context.

[opendatalab/Sciverse-Agent-Tools](https://github.com/opendatalab/Sciverse-Agent-Tools) — agent tool schemas and SDKs for the Sciverse Open Platform, organizing retrieval capabilities into standard tools that LLM agents can call.

[Terax](https://terax.app/) — a terminal-first AI-native development workspace that brings AI development workflows back into the terminal.

[Gitlawb/zero](https://github.com/gitlawb/zero) — a local, autonomous, controllable coding agent built around the idea that your model, machine, and rules are yours.

[Tiktokenizer](https://tiktokenizer.vercel.app/) — an online tokenizer inspection tool for quickly seeing how text is tokenized.

[偷懒工具](https://toolight.cn/) — a collection of small online tools for everyday productivity.

[UniClipboard](https://github.com/uniclipboard/uniclipboard) — a local-first, P2P, end-to-end encrypted cross-device clipboard sync tool with no account or cloud relay required.

### Machine Learning / Optimization / Courses

[Random Reshuffling Dominates Stochastic Gradient Descent](https://arxiv.org/abs/2606.32005) — proves that random reshuffling with suitable step sizes outperforms SGD after any finite number of epochs in smooth convex optimization, resolving a long-standing open question.

[Orca: The World is in Your Mind](https://huggingface.co/papers/2606.30534) — a world model paper page focused on internal world representations and predictive ability.

[Reinforcement Learning of Large Language Models](https://ernestryu.com/courses/RL-LLM.html) — course material on reinforcement learning for large language models.

[DSC 243: Convex Quadratics](https://ddrusvyat.github.io/DSC-243/) — lecture notes on convex quadratic functions from an advanced optimization course.

[Pen and Paper Exercises in Machine Learning](https://arxiv.org/abs/2206.13446) / [GitHub](https://github.com/michaelgutmann/ml-pen-and-paper-exercises) — machine-learning exercises suited for conceptual derivation and exam-style practice.

[Presentations](https://michaelgutmann.github.io/presentations/) — Michael Gutmann's presentations on statistical machine learning.

[Machine Learning Visualized](https://ml-visualized.com/) — visual material for machine-learning concepts.

[IClimbTrees](https://www.iclimbtrees.com/courses) — a collection of AI and machine-learning courses.
