The first weekly issue, published roughly every two weeks. AI was used for categorization, though not perfectly accurate — I decided against manual sorting.

## AI & Machine Learning
### Models & Frameworks
- xAI released [Grok](https://grok.com/) 4.2, with four Agents working simultaneously and strong search capabilities.
- [Gemini 3.1 Pro: Announcing our latest Gemini AI model](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-1-pro/) — Gemini 3.1 Pro is here!
- [GitHub - fishaudio/fish-speech: SOTA Open Source TTS](https://github.com/fishaudio/fish-speech) — Text-to-speech and voice cloning.
- [GitHub - stepfun-ai/NextStep-1](https://github.com/stepfun-ai/NextStep-1) — StepFun's autoregressive image generation model with continuous tokens (ICLR 2026 Oral).

### Papers & Research
- [GitHub - MaximeVandegar/Papers-in-100-Lines-of-Code](https://github.com/MaximeVandegar/Papers-in-100-Lines-of-Code) — Implementing classic AI papers in ~100 lines of code.
- [Understanding Anthropic's Interpretability Research](https://www.zhihu.com/question/1911022705769152635/answer/2004915744811529185) — A nice overview of Anthropic's interpretability work.
- [On Surprising Effectiveness of Masking Updates in Adaptive Optimizers](https://arxiv.org/abs/2602.15322) — A new optimizer: Momentum-aligned gradient masking (Magma).
- [GitHub - ResearAI/AutoFigure-Edit](https://github.com/ResearAI/AutoFigure-Edit) — AutoFigure: Generating publication-ready scientific illustrations (ICLR 2026).

### AI Hardware
- [Taalas | The model is The Computer](https://taalas.com/) — Another AI inference chip company.
  - Ultra-fast HC1 chip achieving ~17k token/s inference on LLAMA 3.1 8B.
  - Try it: [chat jimmy](https://chatjimmy.ai/)

### AI Agents & Tools
- [LobsterAI](https://lobsterai.youdao.com/) — NetEase's open-source AI Agent client.
- [GitHub - RightNow-AI/openfang](https://github.com/RightNow-Ai/openfang) — An Agent OS similar to OpenClaw.
- [GitHub - 1rgs/nanocode](https://github.com/1rgs/nanocode) — Minimal Claude Code alternative in a single Python file (~250 lines, zero dependencies).
- [GitHub - minorcell/memo-code](https://github.com/minorcell/memo-code) — Lightweight coding agent for terminal. [Blog post](https://juejin.cn/post/7605800124883288070) discusses terminal input challenges.
- [Happy - Claude Code Mobile Client](https://happy.engineering/) — Remote-control Claude Code on mobile (though not the most user-friendly).
- [GitHub - Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach) — Let AI agents access social media and streaming platforms (Twitter, Reddit, YouTube, etc.).
